# inventory

A real-time inventory management web app built for a friend's workplace.

## Overview

This app replaces a manual inventory tracking process (previously done via LINE messages) with a simple, mobile-friendly web interface. Staff can view and update stock counts in real time from any device by opening a link — no app installation required.

## Features

- Real-time sync across all devices (Firebase Realtime Database)
- Mobile-friendly UI
- Password-protected edit mode
- Low stock alerts

## Tech Stack

- HTML / CSS / JavaScript (vanilla)
- Firebase Realtime Database

## Setup

1. Clone this repository
2. Copy `app-config.example.js` to `app-config.js` and set your password
3. Open `index.html` in a browser or deploy to Firebase Hosting

## Background

Built as a personal project to solve a real problem at a friend's workplace. Developed with the help of AI tools, iterated based on user feedback.
